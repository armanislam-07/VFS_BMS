### Powertrain Team

Developing the **Battery Management System** for the [Purdue Vertical Flight Systems (VFS)](https://engineering.purdue.edu/Engr/Academics/Undergraduate/student-organizations/PEPC-Groups/vfs) organization.

**Board:** STM32H723GT with NAND memory


**Key Responsibilities:**
- **Battery Monitoring:** Voltage, current, and other battery parameter monitoring.
- **CAN Communication:** Interface with ArduPilot over CAN bus, potentially through an external CAN transceiver board.
- **SPI Communication:** Interface with external peripherals, including ADCs and DACs, for sensor data acquisition and analog signal output.
- **Firmware Development:** Implementing peripheral drivers, communication protocols, and BMS control logic.
